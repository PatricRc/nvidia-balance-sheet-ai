# Editorial assets

Generated with the built-in imagegen tool. Converted to WebP for the local dashboard prototype. Both images are illustrative and represent generic equipment.

## silicon-ledger.webp

Use case: stylized-concept. Asset type: wide landscape editorial cover for an independent corporate financial report about NVIDIA. An unbranded graphite semiconductor die with finely etched silicon and orderly metallic PCB traces on a near-black workbench, photographed as a restrained high-end annual report still life. The die sits right of center, composition dark and quiet across the left half for live typography, narrow lime-green reflected edge light and neutral metal, disciplined museum lighting. 16:9-style wide framing, meaningful shapes visible when cropped to a wide header. No writing, no logos, no watermark, no charts, no graphs, no sci-fi glow.

Strong vertical rhythm with restrained detail and subdued contrast, architectural corporate annual report photography, horizontal landscape composition, no people, no logos, no numbers, no text, no watermark.
