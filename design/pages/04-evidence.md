# 04 · AI Analyst Notes & Evidence

**Browser prototype.** The browser composition uses a numbered claim index with expandable calculations and a separate filing stamp. The full statement lives in chapter 05. The layout table below is a future native report reference.

**Question.** Can a reader reproduce each analytical claim from the source?

**Opening line.** Follow the filing trail. The prototype uses editorial calculation examples and states the AI publication status explicitly.

| Zone | Native layout target and binding |
| --- | --- |
| Header | Fixed fiscal date and comparator. A prominent AI publication status uses text as well as styling. |
| Claim disclosures | x=224–828. Separate Snapshot reconciliation, working capital and debt definitions. Show question, calculation and exact input rows in a stable order. |
| Filing record | x=844–1248. Filing type, accession, period, active URL and description of comparative columns. |
| Future reviewed notes | A reviewed note displays claim, evidence links, review timestamp and a provenance disclosure. A withheld note leaves evidence visible. |

**DAX and model boundary.** Use numeric page measures for deterministic evidence and display labels only after computation. An eventual note visual filters to the exact fiscal date and the approved publication state. Model review must distinguish a missing note, an abstention, a rejected note and an approved one. The public card should surface reviewer status, prompt version and evidence links. Access controls belong in the data layer. A report-level visibility condition only controls presentation.

**Evidence contract.** Each source row carries a stable evidence ID, accession, filing date, exact period, line item or concept, unit, amount, version and URL. Derived claims point to every operand and record the formula and version. Comparative facts retain their actual observation date. A newer filing alone is insufficient evidence of a restatement.

**Check.** Change period with a disclosure open. The new claim and provenance appear together and previous disclosure state clears. Keyboard users can reach the exact values and SEC link. No example displays a generated note or approval claim.
